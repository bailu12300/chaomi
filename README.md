# 早八（zaoba）

硬件行情采集与价格追踪 App，覆盖显卡 / 处理器 / 固态硬盘 / 内存条 / 笔记本五大品类，含资讯社区功能。

## 技术栈

### 客户端（App）
- **Kotlin + Jetpack Compose**（Material 3，米暖色主题）
- **WorkManager**：后台采集调度（3 分钟/型号，12 小时一轮，断点续传）
- **前台服务（Foreground Service）**：强保活，避免采集被系统杀死
- **OkHttp**：网络请求（采集 + API）
- **Android 原生组件**：VideoView（视频播放）、WebView（公众号正文/图片渲染）
- **Coroutines**：异步/并发

### 服务端（早八 API）
- **Node.js**（Express）：REST API，端口 8100
- **MongoDB**：数据存储（行情快照 + 一周历史 + 账号 + 文章/评论/点赞）
- **ffmpeg / ffprobe**：图片压缩（最长边 1080）、视频压缩（H.264 + CRF28）、视频时长校验（≤1 分钟）
- **we-extract**：微信公众号文章解析（粘贴链接 → 自动导入正文）

### 采集架构
- **采集在 App 端**（手机 IP），服务器只存数据不参与采集
- 数据源：慢慢买比价
- 节奏：3 分钟/型号、12 小时一轮，每轮最后 1 小时为保护期（禁止抓取，防污染下一轮）
- 断点续传：App 被杀后台后从断点继续

### 数据流
```
App 采集(手机IP) → 早八 MongoDB → 每 6 分钟同步 → cm01 行情站点(MySQL)
```

## 功能

- **硬件行情**：实时价格、涨跌平（红涨绿跌）、一周走势图（迷你 sparkline）、上一轮价格对比
- **资讯社区**：发文章、富文本（代码块/链接/话题标签/表情/图片/视频）、Markdown 渲染
- **公众号导入**：粘贴 mp.weixin.qq.com 链接自动解析入库
- **互动**：评论、点赞
- **账号体系**：邮箱验证码注册/登录、头像/昵称/个性签名/个性背景
- **数据持久化**：早八存一周，更长历史交给 cm01

## 采集规则（硬约束）

| 项 | 值 |
|---|---|
| 节流 | 3 分钟/型号 |
| 轮次 | 12 小时一轮 |
| 保护期 | 每轮最后 1 小时禁止抓取 |
| 历史保留 | 早八 7 天，更长交 cm01 |
